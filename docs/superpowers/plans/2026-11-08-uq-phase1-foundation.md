# uQ Phase 1 (Foundation) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship `uqd` (theme + per-workspace layout daemon on D-Bus), `uqctl`, the 7×2 theme set with
renderers, uQ's base Hyprland Lua config, and Arch packages, so that installing `uq` gives a
themed Hyprland session whose theme and workspace layouts can be changed live and persist.

**Architecture:** A Cargo workspace with a pure library crate `uq-core` (theme model, renderers,
Lua emitter, schedule, state, atomic writes; no I/O beyond the filesystem) and two binaries:
`uqd` (owns state, talks to Hyprland through a `Compositor` trait, serves `org.uq.Desktop1` with
zbus) and `uqctl` (D-Bus client). Every Hyprland interaction goes through `Compositor`, so the
service logic is tested against a fake and only one adapter knows Hyprland's socket protocol.

**Tech Stack:** Rust (edition 2024, stable), `serde` + `toml` + `serde_json`, `minijinja`
(templates), `zbus` 5 (D-Bus, tokio), `tokio`, `clap` 4, `chrono`, `sunrise` (sun times),
`thiserror`, `tracing`; Hyprland Lua config (verified against Hyprland source 0.57.0, git
`2d2669a1`); PKGBUILD packaging.

**Spec:** `docs/superpowers/specs/2026-11-08-uq-desktop-design.md` (sections 1, 2.1, 2.2, 2.5, 4–8;
this plan is Phase 1 only — shell, settings app, repo integrations, greeter and the scdr focus
feed belong to later plans).

## Global Constraints

- Relationship to Hyprland: **stock upstream, pinned**; no Hyprland patches.
- Hyprland config is Lua. Confirmed API (Hyprland source 0.57.0): `hl.config({...})`,
  `hl.workspace_rule({ workspace = "<sel>", layout = "<name>" })`, `hl.bind(...)`,
  `hl.on("hyprland.start", fn)`, `hl.exec_cmd(cmd)`, `require("/abs/path.lua")` and
  `require("./relative.lua")` (relative to the main config's directory).
- Border colours: `hl.config({ general = { col = { active_border = ..., inactive_border = ... } } })`.
- Valid layout names uQ exposes: `dwindle`, `master`, `scrolling` (Hyprland also has `monocle`;
  uQ rejects it in Phase 1).
- Validation: `Hyprland --verify-config -c <file>`. Live control: `hyprctl eval '<lua>'`,
  `hyprctl reload`, `hyprctl configerrors`, `hyprctl -j activewindow`, `hyprctl -j workspacerules`.
- Config files (spec §2.1):
  - `~/.config/hypr/hyprland.lua` — uQ-installed stub, three `require` lines only.
  - `/usr/share/uq/hypr/base.lua` — packaged defaults.
  - `~/.config/hypr/uq/generated.lua` — written only by `uqd`.
  - `~/.config/hypr/uq/user.lua` — user's file, created empty once, never rewritten.
- Theme render target: `~/.local/state/uq/theme/` (staging dir + atomic rename).
- Daemon state: `~/.local/state/uq/state.toml`.
- Themes: Gruvbox, Dracula, Matcha, Forest, Graphite, Rosewood, Velvet × `dark`/`light` = 14.
  Default on first run: **Graphite dark**.
- Theme ids are lowercase (`gruvbox`, `dracula`, `matcha`, `forest`, `graphite`, `rosewood`,
  `velvet`); variants are `dark` | `light`.
- D-Bus: session bus name and interface `org.uq.Desktop1`, object path `/org/uq/Desktop1`.
- Contrast: WCAG AA (≥ 4.5:1) for every text/surface pair listed in Task 3.
- Packaging target: Arch-family (Arch, Manjaro). `uqd` runs as a systemd **user** unit with
  `Restart=on-failure`.
- Licences: credit Gruvbox (MIT, morhetz) and Dracula (MIT, Dracula Theme) in `themes/CREDITS.md`.

## Review Focus

1. **User hand-edits `generated.lua`.** Expected: `uqd` regenerates it wholesale from state on the
   next change; the file starts with a `-- Generated by uqd. Edit user.lua instead.` header. Test:
   Task 5 `generated_has_do_not_edit_header`.
2. **A broken `user.lua` makes verification fail for a change that is itself fine.** Expected: last
   good `generated.lua` kept, `ConfigError` carries Hyprland's message verbatim, state not
   advanced. Test: Task 8 `failed_verify_keeps_last_good_and_reports`.
3. **Named or special workspaces** (`web`, `special:magic`, names containing quotes or
   backslashes). Expected: emitted as correctly escaped Lua strings; empty selector rejected.
   Test: Task 5 `workspace_selector_is_escaped`, Task 8 `empty_workspace_rejected`.
4. **Missing or corrupt `state.toml`** (first run, crash mid-write, hand edit). Expected: start with
   defaults (Graphite dark, no layouts, schedule off), log a warning, keep running. Test: Task 6
   `corrupt_state_falls_back_to_default`.
5. **Hyprland not running** when `uqd` starts or a request arrives (no
   `HYPRLAND_INSTANCE_SIGNATURE`, socket gone). Expected: files still rendered and persisted,
   live-apply skipped with a warning, D-Bus keeps serving. Test: Task 8
   `compositor_down_still_persists`.

### Task 8: Desktop service

**Files:** Create `crates/uqd/src/service.rs`.

**Interfaces:**
- Consumes: Tasks 1–7.
- Produces:
  - `struct Desktop { paths: Paths, themes: ThemeRegistry, state: State, comp: Arc<dyn Compositor>, sys: Arc<dyn SystemSettings>, events: broadcast::Sender<Event> }`
  - `enum Event { ThemeChanged { name: String, variant: Variant, tokens_path: PathBuf }, LayoutChanged { workspace: String, layout: Layout }, ConfigError(String) }`
  - `enum DesktopError { UnknownTheme(String), InvalidLayout(String), EmptyWorkspace, ConfigInvalid(String), Io(String) }`
  - `async fn set_theme(&mut self, id: &str, v: Variant) -> Result<(), DesktopError>`
  - `async fn set_layout(&mut self, ws: &str, layout: &str) -> Result<(), DesktopError>`
  - `async fn set_schedule(&mut self, s: Schedule) -> Result<(), DesktopError>` (also applies
    `variant_at(now)` if it differs from the current variant)
  - `fn get_theme(&self) -> (String, Variant)`, `fn get_layouts(&self) -> BTreeMap<String, Layout>`
  - `async fn reload(&mut self) -> Result<(), DesktopError>` (re-render from state)
  - `async fn startup(&mut self)` — ensures `user.lua` exists (create empty, never overwrite),
    installs the `hyprland.lua` stub only if absent, then `reload`.
- Commit sequence for any change (one private fn `commit(next: State)`):
  1. render theme → `RenderedFiles`; emit `generated.lua` text.
  2. write candidate to `generated.lua.candidate`; write a temp main config that requires base,
     candidate and user; `comp.verify(temp)`.
  3. `Rejected(msg)` → delete candidate, emit `ConfigError(msg)`, return `ConfigInvalid(msg)`;
     state, `generated.lua` and theme dir unchanged. `NotRunning`/missing binary from verify →
     warn and continue (cannot validate).
  4. `atomic_replace_dir(theme_dir)`, rename candidate → `generated.lua`, `state.save`.
  5. live apply: layout change → `comp.eval(emit_workspace_rule(..))`; theme change →
     `comp.reload()`, `sys.apply(theme)`. `NotRunning` → warn only.
  6. emit `ThemeChanged` / `LayoutChanged`.

- [ ] **Step 1: Tests** (all with `FakeCompositor`, `FakeSystem`, `Paths::under(tempdir)`, real `themes/`):
  `set_theme_writes_files_and_emits`; `set_layout_persists_and_evals` (eval called with
  `hl.workspace_rule({ workspace = "2", layout = "scrolling" })`; `state.toml` has it);
  `failed_verify_keeps_last_good_and_reports` (verify → `Rejected("user.lua:3: syntax error")`:
  `generated.lua` byte-identical to before, `ConfigError` event text equals the message, state
  unchanged); `compositor_down_still_persists` (`running = false`: files + state written, Ok
  returned); `unknown_theme_rejected`; `invalid_layout_rejected`; `empty_workspace_rejected`;
  `startup_never_overwrites_user_lua` (pre-existing `user.lua` content unchanged after `startup`).
- [ ] **Step 2–4:** FAIL → implement → PASS. **Step 5:** Commit `feat(uqd): desktop service`.

### Task 9: D-Bus interface, daemon main and `uqctl`

**Files:** Create `crates/uqd/src/dbus.rs`, `crates/uqd/src/main.rs`, `crates/uqctl/Cargo.toml`,
`crates/uqctl/src/main.rs`; Test: `crates/uqd/tests/dbus.rs`.

**Interfaces:**
- `org.uq.Desktop1` at `/org/uq/Desktop1`:
  - `SetTheme(s name, s variant)`, `GetTheme() → (s name, s variant)`, `SetSchedule(s json)`,
    `SetLayout(s workspace, s layout)`, `GetLayouts() → a{ss}`, `Reload()`, `ListThemes() → as`.
  - Signals `ThemeChanged(s name, s variant, s tokens_path)`, `LayoutChanged(s workspace, s layout)`,
    `ConfigError(s message)`.
  - Errors: `org.uq.Desktop1.Error.UnknownTheme`, `.InvalidLayout`, `.EmptyWorkspace`,
    `.ConfigInvalid`, `.Io` (message = `DesktopError` text).
- `main.rs`: build `Desktop` from `Paths::from_env()`, `startup()`, serve D-Bus, forward `Event`s to
  signals, and run the schedule loop (sleep until `next_transition`, then `set_theme(current, v)`;
  re-plan after every `SetSchedule` and on wake from suspend by capping sleeps at 60 s and
