# uQ

A themeable Hyprland desktop: stock Hyprland (pinned), a Quickshell shell, Rust/cxx-qt apps and
system-wide theming. See [the design spec](docs/superpowers/specs/2026-11-08-uq-desktop-design.md).

Phase 1 (this tree) ships `uqd`, `uqctl`, the theme set and uQ's base Hyprland config.

```bash
cargo test --workspace
```
